# README 图片说明

本目录为项目介绍使用的静态素材，不含个人求职资料。

| 文件 | 来源与用途 |
| :--- | :--- |
| `cover.png` | 2026-10-08 使用 Codex 内置 ImageGen 生成的品牌插画；蓝白配色与现有界面一致，不作为功能界面或产品证据 |
