# eassyjob · 投递素材库

本地求职填写辅助网站，用于保存、按主题及岗位检索填写素材，方便复制到招聘表单。支持导入、编辑、另存为新记录、批量文本预览、中文模板和 JSON 备份。

资料保存在当前浏览器的 IndexedDB 中。项目不包含个人求职资料，不自动提交申请，也不调用模型或同步到云端。

## 本地运行

需要 Node.js 20 或更高版本。

```sh
npm ci
npm run build
npm start
```

打开 http://127.0.0.1:4173 。Windows 完成安装和构建后，也可双击“启动应用.cmd”，通过“停止应用.cmd”停止服务。

```sh
npm test
```

详细操作见 [使用说明](使用说明.md)。更换浏览器或访问地址前，请先导出 JSON 备份。
